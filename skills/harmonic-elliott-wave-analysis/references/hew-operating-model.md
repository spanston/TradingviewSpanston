# HEW Operating Model

Load this reference when a Harmonic Elliott Wave report needs detailed rules, ratio definitions, corrective-pattern checks, or a full validation checklist.

## Core Model

Harmonic Elliott Wave treats market movement as nested A-B-C structures that combine into five-wave fractals. A bullish trend sequence is Wave 1 up, Wave 2 down, Wave 3 up, Wave 4 down, Wave 5 up. A bearish trend sequence is the inverse.

The practical shift from traditional Elliott Wave is discipline:

- Directional waves are built from A-B-C motion.
- Macro counts have priority over local micro counts; lower-timeframe structure is used to prove or reject the macro count, not to distract from it.
- Macro Waves 1, 3, and 5 require visible subwave work whenever data permits. A macro count without subwave evidence is provisional.
- Wave 3 is validated by projection, not just visual strength.
- Alternation is a structural truth test.
- Hard invalidation and flip levels must be explicit.
- A beautiful count without a validation log remains opinion.

## Notation and Degree

Use consistent degree notation:

```text
Highest degree: [1] [2] [3] [4] [5] / [A] [B] [C]
Large degree:   (1) (2) (3) (4) (5) / (A) (B) (C)
Medium degree:  1 2 3 4 5 / A B C
Lower degree:   (i) (ii) (iii) (iv) (v) / (a) (b) (c)
Micro degree:   i ii iii iv v / a b c
```

A completed five-wave fractal creates a completed wave of one higher degree. Do not mix degrees casually.

## Five-Wave Rule Table

| Rule | Bullish Count | Bearish Count | Action if Failed |
|---|---|---|---|
| Wave 2 | Must hold above Wave 1 origin | Must hold below Wave 1 origin | Count invalid |
| Wave 3 | Must exceed Wave 1 high | Must exceed Wave 1 low to downside | Count invalid or incomplete |
| Wave 3 projection | Minimum 176.4% of Wave 1 from Wave 2 | Minimum 176.4% of Wave 1 from Wave 2 | Count suspect |
| Wave 4 | Must hold above B of 3 | Must hold below B of 3 | Count damaged or invalid |
| Wave 5 | Normally exceeds Wave 3 high | Normally exceeds Wave 3 low | Recheck count first |
| B of 5 | Must hold above Wave 4 | Must hold below Wave 4 | Wave 5 structure damaged |

## Projection Formulas

Bullish C target:

```text
Wave C target = Wave B low + (Wave A length * projection ratio)
```

Bearish C target:

```text
Wave C target = Wave B high - (Wave A length * projection ratio)
```

Bullish Wave 3 target:

```text
Wave 3 target = Wave 2 low + (Wave 1 length * projection ratio)
```

Bearish Wave 3 target:

```text
Wave 3 target = Wave 2 high - (Wave 1 length * projection ratio)
```

Bullish Wave 5 target:

```text
Wave 5 target = Wave 4 low + ((Wave 1 + Wave 3 distance) * projection ratio)
```

Bearish Wave 5 target:

```text
Wave 5 target = Wave 4 high - ((Wave 1 + Wave 3 distance) * projection ratio)
```

## Wave C of 3

C of 3 is usually the heart of the campaign.

Bullish evidence:

- acceleration through prior resistance
- strong candles or gaps
- limited pullbacks
- rising slope versus A of 3
- emotional pressure on under-positioned bulls and trapped shorts

Validation:

1. Measure A of 3.
2. Project C-of-3 ratios from B of 3.
3. Confirm C of 3 is not shorter than A of 3.
4. Confirm full Wave 3 reaches at least 176.4% of Wave 1 from Wave 2.
5. Compare slope and result.
6. Drill lower only after the macro structure works.

## Corrective Structures

| Pattern | Structure | Function | Warning |
|---|---|---|---|
| Zigzag | A-B-C | Correction through price | A and C should carry directional force |
| Double Zigzag | A-B-C / X / A-B-C | Extended correction through price/time | Do not call it impulse if Wave 3 floor fails |
| Triple Three | A-B-C / X / A-B-C / X / A-B-C | Complex corrective sequence | Often mistaken for impulse |
| Regular Flat | A-B-C with B near prior extreme | Correction through time | C returns toward A |
| Expanded Flat | B exceeds prior extreme | Trap structure | B-wave strength is deceptive |
| Running Flat | B exceeds prior extreme, C fails to travel far | Strong-trend correction | Easy to abuse to protect a count |
| Triangle | a-b-c-d-e | Contracting time correction | Do not force it from converging lines alone |
| Double Three | W-X-Y | Complex correction through time | Burns time, frustrates both sides |

Wave 2 should not be treated as a triangle in the core HEW framework.

## Wave B Rules

Wave B is the wild card.

- Inside an impulse, B usually moves countertrend and must respect the relevant invalidation level.
- Inside a correction, B can move with the larger trend, retest or exceed the prior extreme, and trap traders.
- If B becomes too emotional, wait for confirmation instead of forcing the count.

## Alternation

Wave 2 and Wave 4 should alternate in at least one of:

- depth
- complexity
- duration

If Wave 2 is deep, simple, and fast, Wave 4 is more likely shallow, complex, and slower. If Wave 2 is shallow and brief, Wave 4 is more likely deeper or more time-consuming.

Weak alternation is not automatic invalidation, but it reduces confidence and may imply a complex correction rather than a clean impulse.

## Top-Down Workflow

1. Zoom out.
2. Attempt the highest-degree macro count first. Do not let an attractive lower-timeframe count override the macro count unless the macro count fails a hard rule, ratio requirement, or visible subwave test.
3. Find the three major markers:
   - longest A-B-C in the middle of the trend, often Wave 3
   - corrective A-B-C and following A-B-C that makes the new high/low, often Wave 4 and Wave 5
   - starting A-B-C off the major low/high and following correction, often Wave 1 and Wave 2
4. Confirm Wave 3 with the 176.4% floor.
5. Confirm Wave 5 normally exceeds Wave 3.
6. Cross-check critical supports or resistances.
7. Confirm A-B-C internals inside macro Waves 1, 3, and 5, especially A of 3 versus C of 3. Classify the corrective internals of Waves 2 and 4.
8. Drill down only after the macro count works, and use the drilldown to fill missing subwaves rather than to create an unrelated count.

## Projection Map Requirements

A projection map must include:

- primary count
- active wave
- whether the highest-probability macro-following path is impulsive continuation or complex correction
- next target box
- flip level
- hard invalidation
- alternate-count trigger
- early, mid-structure, terminal, or no-trade state

Use target clusters, not isolated ratios. Strong clusters may combine Wave 3 projection, C-of-3 projection, lower-degree projection, prior support/resistance, channel boundary, and momentum divergence.

Projection discipline:

- If the macro count supports continuation, project the next impulsive wave and its visible subwaves.
- If the macro count supports correction, project the most likely complex corrective sequence (`A-B-C`, `W-X-Y`, flat, triangle, double three, or triple three).
- Do not publish a projection that is only a set of horizontal levels. Levels must support a count path; they are not the count.

## Invalidation and Flip Levels

Hard invalidation breaks a rule. The count is wrong.

Flip level changes posture but may not invalidate the count.

Every report must distinguish the two.

## Trade Setup Logic

Best long structural locations:

- Wave 2 completion above Wave 1 origin
- B-of-3 support after A of 3
- Wave 4 support above B of 3
- B of 5 support above Wave 4
- breakout or retest after HEW structure confirms

Best short structural locations are the inverse.

Stand aside when:

- macro count is not validated
- price is in a messy B wave
- alternate count materially changes posture
- price is between flip and invalidation with no edge
- C of 3 is vertical and late
- risk/reward is poor
- target confluence is absent

## Chart Construction Standards

Macro structure chart:

- full weekly or monthly campaign
- primary macro count
- subwaves inside macro Waves 1, 3, and 5 when visible
- regime header
- flip level
- hard invalidation
- major target or demand/supply zone

Projection map:

- forward path from the highest-probability macro-following count
- impulsive continuation or complex corrective scenario explicitly labeled
- target box
- alternate trigger
- invalidation
- supporting fib levels

Drawing rule:

- Use Elliott tools or connected trend lines for wave counts and subwave counts.
- Use horizontal lines only for non-count decision levels such as invalidation, flip, floor, or target boundaries.
- Never draw wave counts with horizontal lines.

Alternate count chart:

- why alternate differs
- activation level
- invalidation level
- next implication

Wave anatomy chart:

- A/B/C of 3
- local corrective anatomy
- compact fib relationships
- terminal behavior if C of 3 or Wave 5 is late

Risk architecture chart:

- only for a live trade
- entry, stop, target, risk/reward

## Report Checklist

Before publishing:

```text
[ ] Macro regime is stated.
[ ] Primary macro count is labeled.
[ ] Subwaves are mapped inside macro Waves 1, 3, and 5 when visible.
[ ] Alternate count is meaningful.
[ ] Wave 3 meets or exceeds 176.4% of Wave 1.
[ ] C of 3 is not shorter than A of 3.
[ ] Wave 2 respects Wave 1 origin.
[ ] B of 3 respects Wave 2.
[ ] Wave 4 respects B of 3.
[ ] B of 5 respects Wave 4.
[ ] Wave 2 and Wave 4 alternate.
[ ] Corrective pattern is identified.
[ ] Projection follows either the highest-probability impulsive path or the highest-probability complex corrective path.
[ ] Target box is based on confluence.
[ ] Flip level is visible.
[ ] Hard invalidation is visible.
[ ] Trade setup is separated from structural thesis.
[ ] Risk/reward is acceptable if trade language is used.
[ ] Validation log is complete.
```

## Posture Labels

| Posture | Meaning | Action |
|---|---|---|
| BULLISH | Primary structure supports upside continuation | Buy pullbacks or breakouts only at defined zones |
| BEARISH | Primary structure supports downside continuation | Sell bounces or breakdowns only at defined zones |
| ACCUMULATION | Macro thesis positive, but timing still corrective | Scale only in validated demand zones; avoid chasing |
| STAND ASIDE | Count unresolved or risk/reward poor | No trade until confirmation |
